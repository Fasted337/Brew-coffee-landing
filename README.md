# Brew & Co — лендинг кофейни

Одностраничный сайт вымышленной кофейни.

🔗 **Демо:** https://brew-coffee-landing.potapovt60045.workers.dev

## Что внутри
- Адаптивная вёрстка (десктоп + мобильный)
- Navbar с бургер-меню на мобильных
- Hero с фоновым изображением
- Меню с тремя категориями (кофе, десерты, завтраки)
- Отзывы гостей
- Форма бронирования столика
- Footer с контактами и часами работы

## Технологии
- HTML
- CSS (flexbox, grid, медиазапросы)
- JavaScript (бургер-меню)
